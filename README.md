# OIR Viewer

`.oir` を中心とした顕微鏡画像スタックを、2D・3D・プレート単位で表示し、
図や PDF として保存するデスクトップアプリです。

## 主な機能

- `.oir` / `.oib` / `.oif` / `.tif` / `.tiff` / `.nd2` / `.lif` / `.czi` の表示
- チャンネルごとの色、表示、Min / Max、Z / T、MIP の調整
- 2D、Split、Compare、3D ボリューム表示
- マウスまたは座標で範囲を指定するクロップと、クロップ画像の保存
- 画面内スケールバー、ROI、ラインプロファイル、面積計測
- TIFF / PNG / JPEG、3D画像、Z投影 OME-TIFF の保存
- ファイルごとの表示設定の記憶と「元ファイルの設定に全て戻す」
- MATLプレートのウェル選択と、条件表付き Plate PDF の作成

Z が2枚以上ある画像は3D、1枚の画像は2Dで開きます。3Dの初期Qualityは
`Maximum`、仰角は0°、拡大率100%です。

## 基本的な使い方

1. **Open** で画像を選びます。
2. チャンネル、Min / Max、Z / T、表示モードを調整します。
3. **Save As** で表示画像を、**Projection** でZ投影を保存します。
4. 3Dでは角度、拡大率、Z範囲を調整し、表示中の条件で保存します。

起動時はファイルを自動で開きません。複数のタブを閉じるときは
**File Manager** で対象をチェックし、まとめて閉じられます。

画像の読み込み中は進捗バーを表示します。割合を測れない処理は、推測値を
出さず動作中のバーで示します。

分割された `.oir` は、メインファイルと `_00001` などの付随ファイルを同じ
フォルダに置き、メインファイルを **Open** から選んでください。

## Plate PDF

1. **Plate** で撮影フォルダを選び、必要なウェルを開きます。
2. 各ウェルのタブで3D表示を調整します。
3. **Plate Save** で条件・メモ、保存先、ファイル名を設定してPDFを作成します。

ボリューム解像度とPDF画像解像度は初期状態で `Max` です。条件表は
「Well番号・条件・メモ」で始まり、列の追加や編集もできます。条件は画像を
隠さないよう画像の上に表示され、全内容はPDFの条件表ページに入ります。

「空きウェルは表示しない」は初期状態で有効です。無効にするとプレート全体の
配置で出力します。保存中は進捗が表示され、完了すると結果ダイアログが開きます。

## インストール

[Releases](../../releases) から環境に合うインストーラをダウンロードしてください。
PythonやJavaを別途インストールする必要はありません。

- macOS: Appleシリコン用 `arm64.dmg`、Intel用 `x64.dmg`
- Windows: `OIR Viewer Setup <version>.exe`

Apple / Microsoft への登録をしていないため、初回のみOSの確認が表示されます。

- **macOS** — アプリを一度開こうとしたあと、**システム設定 → プライバシーとセキュリティ**を開き、
  下の方に出る **このまま開く** を押してください。macOS 15 以降は右クリック →
  開く では許可できません。
- **Windows** — **詳細情報 → 実行**を選んでください。

## 困ったとき

メニューの **ヘルプ → ログフォルダを開く** からログを確認できます。不具合を
報告する際は、直近のバックエンドログを添付してください。
